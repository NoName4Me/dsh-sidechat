## 2. 发布与回归

- [x] 维护者本地完成基本功能验收。
- [ ] 由维护者手动触发 npmjs.org 发布，核对公开包内容与 `latest` dist-tag。
- [ ] DSH Desktop 插件管理器从公开 npm 安装、启用、卸载和更新。
- [ ] 鼠标拖动选择过程中不闪烁；松开后原生「引用文本 / 侧聊」胶囊完整可用。
- [ ] 全回复与选区的来源定位范围正确；长文本和重复片段不会误导用户。
- [ ] Light、Fork 各完成真实模型多轮交互；主对话消息、顺序与草稿不受影响。
- [ ] 真实模型尝试调用工具时，Host 侧 deny-all 守卫生效，包括只读工具。
- [ ] 重启 DSH 后恢复侧聊；归档/恢复和升格后的 Session 可见性正确。
- [ ] 主对话草稿回填**不自动发送**；权限与 Session 归属无法绕过。
- [ ] 深色/浅色、窄窗口和减少动画设置下布局正常。

## 3. 后续增强（不阻塞当前版本）

- 主 Agent 在用户明确授权时检索指定侧聊摘要或引用，不自动污染主线。
- 复用 DSH 原生 Chat 的富媒体与工具消息渲染。
- 为选区锚点补充稳定位置记录，解决相同文本重复出现时的歧义。
- 视需要引入更高效的历史订阅和多进程存储策略。
- 在宿主升级时重点回归独占式 Quote Seat 的 Portal 接入。

## 4. 工程约束

- npm 包名：`@jonge/dsh-sidechat`；运行时标识：`dsh-sidechat`、`/sidechat`、`state/sidechat.json`、`session-sidechat-`。
- 侧聊的唯一目录位于 DSH 原生右 Sidebar；不恢复额外的悬浮圆点目录。
- 发布工作流只手动运行，正式版使用 `latest` 标签。
- 不为早期试验包维护存储路径、模块 ID 或 Session ID 兼容代码。
- 构建与 CI 成功不能替代 Desktop 真实模型和体验验收。
